ROAA AGENCY — HTML VERSION
================================

تشغيل الموقع:
1) فكّي ضغط الملف كاملًا.
2) افتحي مجلد Roaa_Agency_HTML.
3) انقري مرتين على index.html — لا تحتاجين npm أو Node.js أو Terminal.

التعديل:
- افتحي index.html في VS Code.
- النصوص العربية والإنجليزية موجودة تحت تعليق: EDIT WEBSITE TEXTS HERE
- الألوان والتنسيق موجودة داخل وسم <style> في نفس الملف.
- الصورة الرئيسية موجودة في assets/hero-devices.png

الرفع على Hostinger:
- ارفعي محتويات المجلد إلى public_html.
- يجب أن يكون index.html مباشرة داخل public_html.
